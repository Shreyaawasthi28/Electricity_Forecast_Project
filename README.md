## 🧠 **About the Project**
This project predicts **future electricity demand** using:
- Past consumption patterns  
- Weather conditions  
- Time-series lag features  
- Machine Learning (LightGBM)  

✔ Accurate demand forecasting  
✔ Beautiful interactive dashboard  
✔ Ready for final-year submission, resume & GitHub  

---

## ⚙️ **Features**

### 🔸 1. Intelligent ML Model  
- LightGBM Regressor  
- Lag & rolling features  
- Weather + Demand fusion  

### 🔸 2. Data Engineering  
- Timestamp parsing  
- Feature extraction  
- Weather merge  
- Clean feature dataset  

### 🔸 3. Streamlit Dashboard  
- Live demand visualization  
- Dataset preview  
- Future demand prediction  
- Modern dark theme UI
